# 学堂在线微信扫码登录

控制台的「微信扫码登录学堂在线」使用学堂在线网页端当前的扫码协议：服务端通过 `wss://www.xuetangx.com/wsapp/` 请求一次性二维码，扫码完成后把短期令牌提交给学堂在线的微信登录接口，并读取响应中的平台 Cookie。

扫码得到的 Cookie 不会返回给浏览器，也不会写入 `localStorage`、日志或任务事件。服务端会先用 Cookie 调用学堂在线用户资料接口确认平台身份，再沿用现有的平台账号绑定流程，用凭据密钥加密保存。正式账号和测试账号仍按原有角色、账号互斥和权限规则处理；Cookie 粘贴入口继续可用。

使用方式：

1. 登录本项目控制台，在正式账号面板点击「微信扫码登录学堂在线」。
2. 使用微信扫描二维码并在微信中确认授权；二维码约 60 秒过期，服务端会显示失败原因并允许重新获取。
3. 连接成功后，平台账号会出现在正式账号面板，后续课程任务直接使用该账号。

如果学堂在线调整 WebSocket、二维码或登录接口，扫码会安全失败并要求重新连接，不会盲目保存不完整的 Cookie。该功能依赖学堂在线当前网页登录协议，不需要在本项目配置微信 AppID 或 AppSecret。
