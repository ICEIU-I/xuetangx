# 管理中心与共享答案采集

管理员登录后直接进入管理中心，不展示学习控制台或任务启动入口。管理中心提供概览、答案采集账号、用户管理及管理员密码设置。

管理员在「答案采集账号」粘贴专门用于获取标准答案的平台 Cookie，可添加多个账号、更新同一账号的 Cookie、校验有效性或停用账号。保存前验证平台身份；Cookie 使用现有 AES-GCM 密钥加密，接口只返回备注、账号标识和有效状态，成功后清空输入。已绑定个人角色的账号不能直接改成共享采集账号。

普通用户只需连接自己的正式账号。任务扫描发现当前班级、练习、题目版本缺少标准答案时，主进程选择共享采集账号；已有个人采集账号仍作为兼容后备。采集账号自身取得的 SKU 和访问参数不复制给正式账号。账号凭据不进入子进程；全站共享标准答案，私有任务、日志和学习状态仍按用户隔离。

同一个平台账号可以由多个网站用户分别连接，每个用户都必须提交并验证自己的 Cookie。绑定、凭据和任务记录分别保存；重新连接或断开仅影响当前网站用户。防重复操作、未知提交结果及累计网络重试次数仍按平台真实身份共享，换一个网站账号不会恢复提交机会。全站采集账号继续使用独立平台身份，不能同时作为个人学习账号。

## 自动免费加入

仅当共享采集账号未选课且本地题库缺少答案时尝试加入：

1. 正式账号先通过当前班级的访问校验。
2. 使用采集账号读取商品基本信息、班级列表、当前班级 SKU。商品 sign、course_sign、商品 ID 和班级真实 ID 必须匹配。
3. 只选择 `sku_info` 中 `current_price` 明确为零且状态为 5/6（可加入）的 SKU。价格缺失、付费 SKU、未开放/关闭、升级或试学促销均不自动选择；没有合适选项时提示等待选课。
4. 主进程先提交 PostgreSQL 操作记录，再调用官网免费加入接口。不能调用支付接口。
5. 回查该采集账号的课程列表，确认相同班级后才继续获取习题。网络断开、响应不明及已发送但未确认的操作跨重启保留，不盲目重发。多个任务同时加入同一账号同一课程合并执行。
6. 平台要求补充资料、访问拒绝或免费 SKU 不开放练习时如实阻塞，不猜测身份或绕过权限。

新增或更新采集账号可唤醒等待账号/选课的采集分支；已暂停、停止或完成的任务保持原状态。停用或更新凭据时取消受影响的采集进程，其他模块继续。服务更新后的未完成任务仍按原恢复策略保持暂停，需要用户手动继续。

## 用户管理

支持按邮箱搜索和分页，查看绑定平台账号、学习记录数量、有效会话、CLI 令牌及已答题数量；可修改普通用户邮箱、重置密码、启用/禁用或撤销登录。修改账号信息会撤销会话与令牌。管理员个人密码从账号设置修改。管理界面没有删除业务与防重复记录的入口。

验证使用真实 PostgreSQL、模拟平台和真实 Go 子进程，覆盖免费/付费/班级错配、未知结果恢复、并发加入、迟到共享账号补齐答案、凭据权限及管理员接口隔离；此轮未执行真实平台选课或作答写入。
